# 实验规划：主张驱动的路线图

## 研究问题与主张层级

**核心问题：** 在强、预注册的功能连接（FC）基线之上，抑郁症（MDD）静息态 FC 的图论摘要是否带来可重复、样本外的增量信息？

**C1（主主张）：** 在中心感知的样本外验证中，将三项预注册图论摘要加入网络对 FC 均值后，可提升样本外诊断判别能力。

**C2（关键次要）：** 在同一图块加入后，可在 MDD 参与者中改善连续 HAM-D 严重程度的样本外预测。

**C3（稳健性）：** 任一预测增量在留出中心及预注册图构造敏感性下保持稳定。

**C4（解释边界）：** 结果量化的是所选表示之间的预测冗余或互补性；其本身不能证明生物学机制或临床效用。

## 阶段 0 — 数据与方案锁定

**目的：** 在不查看结局的前提下，确认目标队列与验证设计可行。

1. 按条款获取 REST-meta-MDD 发布版本，归档版本号、来源 URL/访问日期、文件校验和、代码本及许可限制。
2. **仅**审查数据可用性与 QC：参与者数量、中心归属、各中心诊断重叠、HAM-D 可用性、年龄/性别/头动字段、扫描时长及预处理衍生数据。**不得**计算与诊断相关的 FC/图效应或模型得分。
3. 应用锁定的纳排规则：成人；MDD 或健康对照；最低影像 QC；必需诊断与中心；症状分析另设完整病例队列。
4. 根据中心样本量与组别覆盖评估外部留出可行性；在**任何**模型拟合前冻结合格留出中心。若不可行，将重复的嵌套留一中心验证冻结为主分析。
5. 预注册方案、分析代码骨架、折划分逻辑、图定义、计划对比及缺失/排除报告。

**门槛 0：** 仅当中心感知验证可行且可用队列在计划分组折下能稳定拟合时继续；记录决策与计数。否则在结局建模前修订设计；未经修正案不得替换其他数据集。

## 阶段 1 — 影像 QC 与特征提取

1. 固定 Schaefer-200 图谱与规范网络标签。
2. 在单一锁定的预处理/QC 策略下处理或获取有文档的区域时间序列；按中心与组别报告头动与保留扫描长度。
3. 计算 Pearson FC 与 Fisher-z 边，对角线及缺失/无效脑区处理规则固定。
4. 构建 FC-1（网络内均值）；FC-2（全部唯一网络对均值）；FC-3（折内拟合的全边 PCA，维度与 GRAPH 匹配）。
5. 在 10%、15%、20% 稀疏度下构造正权无向比例图；以固定定义与随机种子/重启计算全局效率、平均聚类系数与模块度；各指标以密度上归一化 AUC 汇总。
6. 生成预注册的二值图、5%/25% 密度及可选 GSR 敏感性特征，禁止结局导向选择。
7. 在合成/示例矩阵上核对特征维度、有限值、受试者对齐与特征计算稳定性；与结局推断分离。

**交付物：** 数据流图/表、特征字典、QC 报告、版本化特征生成代码、受试者–行号不可变映射。

## 阶段 2 — 嵌套、中心感知的模型拟合

### 诊断

拟合 nuisance 结构相同的正则化 logistic 模型：**仅 nuisance**；**nuisance + FC-1**；**nuisance + FC-2**（主基线）；**nuisance + FC-3**；**nuisance + GRAPH**；**nuisance + FC-2 + GRAPH**（主联合模型）；**nuisance + FC-3 + GRAPH**（维度匹配敏感性）。各对比共用同一外层折与参与者。

### HAM-D

在 MDD/HAM-D 子集上拟合对应的正则化线性模型。HAM-D 为连续变量，不做事后二分化。采用完整病例结局观测，并披露子集样本量与缺失情况。

### 折划分与泄漏策略

优先采用锁定的中心留出作外部验证，并在发现集上进行分组嵌套 CV。若外部留出不可行，采用外层与内层折均按中心分组的重复嵌套 CV。插补、标准化、PCA、协调/残差化、正则化选择与阈值选择**均在训练数据内**完成。汇总前先保存折外预测与折分配。不得用留出结局数据选择表示或图稀疏度。

### 评价指标

**诊断：** 配对 ΔAUC、Δlog loss、平衡准确率、训练折选定阈值下的灵敏度/特异度、校准斜率/截距与 Brier 分数。**症状：** ΔR²、ΔRMSE、校准图与残差诊断。采用中心感知 bootstrap 或预注册分组置换法报告 95% 区间；说明重采样单位与方法。

## 阶段 3 — 确认性推断

1. 评估 C1：在锁定验证预测上比较 FC-2 + GRAPH 与 FC-2 的配对 ΔAUC。报告点估计、95% 区间、精确 p 值（若计算）、绝对模型表现、校准及中心异质性。
2. 若 C1 固定顺序门槛通过，评估 C2：HAM-D 的配对 ΔR²/ΔRMSE。无论门槛是否通过均报告区间。
3. 将 FC-3 + GRAPH 作为关键维度对照；若一致，支持「结果并非单纯参数数量或低维度假象」的解读。
4. 估计分中心与留一中心对比；展示中心间差异与参与者数量。勿仅凭合并的内部 CV 声称可迁移性。
5. 应用预注册确认性族-wise 程序；探索性特征族与敏感性组内采用 FDR，全部估计均展示。

## 阶段 4 — 稳健性与失败分析

无论主结果如何，运行所列全部敏感性：二值图构造；5% 与 25% 稀疏度的正权图；可选 GSR 预处理；nuisance/中心调整敏感性；仅图块与各图指标族消融；FC-1 与维度匹配的 FC-3 基线；分中心 vs 留一中心结果。在多元宇宙表中汇总 ΔAUC/ΔR² 的方向、幅度与区间。不得将最有利变体选为主结果。

通过绝对表现、校准、区间宽度与中心异质性分析「空对空」结局。若基线与联合模型均无法超过 modest 参照基准，须报告。这仍是对特征层面预测效用的有边界评估，而非生物学无关之证。

## 阶段 5 — 报告与发布

围绕预注册主张组织文稿：参与者流程图、中心表、特征定义图/表、验证示意图、表现与不确定性图、中心层面增量图、敏感性矩阵。报告方案偏离与全部计划分析。在数据使用/隐私规则允许范围内共享代码、环境锁定文件、折定义、汇总预测及衍生特征。附简明结果–主张对照表，避免将预测结果 overstretch 为机制结论。

## 必备图表

1. 入组流程与各中心/组别样本量表。
2. 特征构造示意图（FC-1/FC-2/FC-3/GRAPH 定义）。
3. 嵌套/中心感知验证示意图。
4. 样本外 ROC/校准与配对 ΔAUC 区间图。
5. HAM-D 观测–预测与配对 ΔR²/ΔRMSE 区间图。
6. 分中心/留一中心增量效应森林图。
7. 敏感性矩阵（全部预注册构造选择及估计区间）。

## 预注册决策表

| 观测模式 | 允许得出的结论 |
|---|---|
| 主 ΔAUC 为正、不确定性区间不含零、中心一致、FC-3 对照一致 | 在该队列与验证设定下，有证据表明该图块相对所指定 FC 摘要具有增量预测信息 |
| 合并点估计为正但区间跨零或中心敏感性大 | 增量价值不确定或存在异质性 |
| 主结果为正但维度匹配的 FC-3 对比为空或反向 | 增益可能来自表示/维度；不可泛化为图特异增量 |
| 图块无增量且 FC 基线有预测力 | 在测试条件下，图摘要相对所选 FC 表示附加价值有限 |
| FC 与图模型均弱 | 该队列中这些特征集预测价值有限；不能推断拓扑与生物学无关 |
| 不同图构造或预处理下方向改变 | 增量价值依赖分析选择 |
| 诊断有增量、HAM-D 无增量 | 诊断与症状预测不同；勿跨结局泛化 |

## 里程碑与依赖

| 里程碑 | 产出 | 依赖 / 停止条件 |
|---|---|---|
| M0：数据锁定与可行性 | 版本化队列说明与中心映射 | 分组验证无效或关键变量缺失则停止/修订 |
| M1：方案冻结 | 带时间戳的分析计划与代码骨架 | 须先于任何结局建模 |
| M2：QC 与特征 | QC 报告与冻结特征表 | 解决对齐与无效指标问题，且不偷看结局 |
| M3：嵌套拟合 | 折外预测与日志 | 全部变换须折内完成 |
| M4：确认性分析 | C1/C2 估计、区间、多重性记录 | 固定顺序；无论显著与否均报告 |
| M5：稳健性与报告 | 敏感性矩阵、图件、文稿草稿 | 含全部计划变体与偏离 |
